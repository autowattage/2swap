# 2swap
this is the source files of 2swap, a DIY tv head.

the name 2swap comes from a forth command (where ABCD in the stack translates to CDAB).

Project made for hack club's alleyway program. He first debuted at hackaday supercon 9 and has additionally visited Open sauce 2026!

## specs
twoswap's frame is a cardboard construction ([dimensions](./tvhead/CONCEPT.png)). inside contains a bike helmet, a [laptop screen](https://www.ebay.com/itm/352771352699) + LVDS -> HDMI board, and a raspberry pi zero 2 w. attached is a USB hub with a USB microphone and mini bluetooth keyboard.

said pi zero 2w has dietpi installed, and pygame software runs the display.
