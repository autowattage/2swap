# 2swap's head

2swap runs on a raspberry pi 5 and uses pygame to display its graphics.

2swap's frame was planned to be made with 3d print, but is now being made with cardboard.

## 2swap's software
Notes before running:
- you will have to manually adjust audio levels in mouth.py
- you will have to manually set the amount of audio channels in your USB device in mouth.py (twoswap uses a USB microphone, which has 1 in-channel)

F to toggle fullscreen
